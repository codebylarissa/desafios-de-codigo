# 🎯 Desafios de Código — Beecrowd & Exercism

Este repositório contém as minhas resoluções de problemas e desafios de lógica de programação das plataformas **Beecrowd** e **Exercism**, desenvolvidas em **Java**.

---

## 📁 Estrutura do Projeto

Os arquivos de código estão organizados na pasta `src/` divididos por plataforma:

```text
desafios-de-codigo/
├── src/
│   ├── beecrowd/       
│   └── exercism/       
├── .gitignore
└── README.md
```
